전국 단위 청소년 컴퓨터 사이언스 학회의 웹 서비스입니다. Zenodo처럼 영구 식별자와 인용 포맷, 버전 관리를 갖춘 논문·프로젝트 아카이브와, 신고 기반으로 관리되는 커뮤니티 게시판으로 이뤄집니다. 기획과 기능 명세 단계입니다.

무엇을 만드나

대한민국 청소년이 쓴 논문과 프로젝트를 올리고, 인용하고, 이야기 나눌 수 있는 전국 단위 웹 서비스입니다. 학교 인증 없이 이메일과 비밀번호로 가입하고, 학교명은 자유롭게 입력합니다. 크게 두 축입니다.

  • 논문·프로젝트 아카이브: 운영진의 사전 승인 없이 올리고, 신고로 사후 관리합니다.
  • 커뮤니티 게시판: 자유, 질문, 스터디·프로젝트 모집, 공지 카테고리와 댓글.

논문 아카이브

Zenodo에서 가져온 것

논문 하나(concept)에 영구 식별자 하나를 붙입니다. 형식은 KSCA-{YYYY}-{NNNNNN}으로, 연도별 6자리 일련번호를 학회 전체 통합 카운터로 발급합니다. 같은 논문의 새 버전을 올려도 식별자는 그대로 두고 버전 번호만 올립니다.

상세 페이지에서는 APA와 BibTeX 인용을 자동으로 만들어 복사할 수 있게 합니다.

식별자   KSCA-2026-000042

@misc{ksca_2026_000042,
  author = {...},
  title  = {...},
  year   = {2026},
  note   = {KSCA-2026-000042},
}

신고 기반 관리

사전 승인이 없는 대신, 같은 대상에 신고가 3건 쌓이면 자동으로 비공개 상태가 되고 운영진 검토 큐로 넘어갑니다. 운영진이 최종적으로 삭제를 확정하거나 복구합니다. 게시판 글도 같은 방식으로 관리합니다.

이 로직은 신고가 들어올 때마다 실행되는 Postgres 트리거로 구현할 계획입니다. 식별자 발급은 카운터를 원자적으로 올리는 함수로 처리해, 동시에 여러 명이 올려도 번호가 겹치지 않게 합니다.

create or replace function generate_concept_id() ...
  -- paper_counters를 원자적으로 증가 (INSERT ... ON CONFLICT DO UPDATE)
  -- SECURITY DEFINER로 RLS를 우회해 카운터만 갱신

데이터

기술 스택은 Percentage와 같은 Next.js와 Supabase, 배포는 Vercel입니다. 파일은 비공개 버킷에 두고 짧게 만료되는 서명 URL로만 내려받게 합니다.
